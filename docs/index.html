How It Works

Step 01
📡
Fetch

GitHub Actions wakes at 07:00 UTC and fetches articles from RSS feeds (TechCrunch, VentureBeat, The Verge, Wired, IEEE Spectrum, MIT Tech Review), the Hacker News Algolia API, and arXiv CS.AI/ML/CL/NE categories.

Step 02
🧹
Deduplicate & Classify

Articles are deduplicated by URL and title hash, then classified into one of five categories using keyword scoring across the title and description text.

Step 03
📊
Score & Rank

Each article receives a score based on recency (5-day decay), source authority (arXiv, IEEE, MIT top-weighted), and title length quality. The highest-scoring recent item becomes the Featured Story.

Step 04
🖥️
Render & Deploy

A single self-contained HTML file is generated in docs/, committed to main, then force-pushed to the gh-pages branch for GitHub Pages.
