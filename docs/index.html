Your Intelligence Feed for Everything AI — Fresh Every Morning

AI Pulse is a fully automated daily newsletter that curates the most important developments in artificial intelligence. Every morning at 07:00 UTC, a GitHub Actions workflow pulls fresh articles from 11+ sources — arXiv pre-prints, TechCrunch, VentureBeat, The Verge, Wired, IEEE Spectrum, MIT Tech Review, OpenAI Blog, Google AI, Hugging Face, and HackerNews — classifies them into five topic categories, ranks by recency and source authority, and regenerates this page automatically.

No editors. No ads. No paywalls. Pure AI signal.

⚙️ How It Works
📡
11+ Live Sources
RSS feeds from major AI publications, arXiv CS papers (AI, ML, NLP, NE, Robotics), and HackerNews via the Algolia API — all pulled fresh each morning.
🗂️
Smart Classification
Each article is matched against curated keyword sets for five categories: Research, AI Agents, Products, Industry, and Open Source. URL fingerprints eliminate duplicates.
📊
Recency Ranking
A composite score weighs freshness (exponential decay over 8 days), source authority, and HackerNews engagement to surface the highest-signal stories first.
⚡
Zero-Infra Deploy
A cron-scheduled GitHub Actions workflow runs fetch_news.py, commits docs/index.html, then the deploy workflow publishes to GitHub Pages automatically.
