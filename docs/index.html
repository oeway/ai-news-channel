How it works

Fully automated

A GitHub Actions workflow runs the whole pipeline daily

Step 01
Fetch
RSS feeds, arXiv API, and Hacker News are polled every morning at 07:00 UTC.
Step 02
Classify
Each article is scored for freshness and assigned to one of five AI categories using keyword matching.
Step 03
Rank
Articles are ranked by recency and source credibility. The top story becomes the featured headline.
Step 04
Publish
A clean HTML newsletter is generated and deployed to GitHub Pages automatically.
