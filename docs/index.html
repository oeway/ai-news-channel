Uses disagreement between specialist sub-agents as a signal to recruit additional tools mid-inference. On science QA requiring image + text, DART reduces tool over-calling by 31% while matching accuracy of exhaustive tool use — a meaningful step toward compute-efficient agentic reasoning.
